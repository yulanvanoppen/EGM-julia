# Reference files

Generated by `matlab/export_reference.m` from EGM-v2 commit `3c83609`. One MAT v7 file per case: `HS_P`, `HS_P_sub`, `GLV_X3`, `STAT5`, `STAT5_patched`.

Notation: K states, P free parameters, L observed states, T data time points, Tg inference time points (`t_gm`), n E-M iterations, Tf = 81 fine-grid points, and `card_k` the spline basis size for observed state k. Unless stated otherwise, stacked vectors over states and time are **state-major**, with index `t + T·(k−1)`. MATLAB drops trailing singleton dimensions, so use `dims(x, n)` from `test/reference.jl` when checking shapes.

## `meta`
| Field | Contents |
|---|---|
| `name` | Case name |
| `patched` | Whether `FilterPatched` was used |
| `M` | K×K noise-mixing matrix (= Φ(0) in `System.auxiliary`) |
| `beta0` | Initial parameter guess |
| `egm_commit`, `matlab_version`, `date` | Provenance |

## `data`
| Field | Contents |
|---|---|
| `traces` | T×L measurements |
| `t` | Data time points |
| `observed` | Indices of the observed states |
| `T`, `L`, `N` | Dimensions |
| `t_gm` | Inference grid |
| `t_fine` | Fine plotting grid |
| `truth_original` | Noise-free trajectories from the generator (all states) |
| `truth_beta` | Parameters used to generate the data |

## `settings`
The `smoothing`, `filter` and `inference` settings structs exactly as built by the EGM constructor.

## `system` (Phase 1)
| Field | Contents |
|---|---|
| `name`, `K`, `P` | Model name and dimensions |
| `states`, `parameters`, `parameters_variable` | Names (cell arrays) |
| `k0` | Free-parameter nominal values |
| `x0` | Initial conditions from the model file |
| `fixed_names`, `fixed_values` | Fixed parameters |
| `eval_states` (Tg×K), `eval_times`, `eval_beta` | Test points: final smoothed states and final β |
| `g` | (K·Tg)×P; block k holds rows g_k(x(t))ᵀ for all t |
| `h` | Tg×K |
| `rhs` | Tg×K, equal to g·β + h |
| `df` | (K·Tg)×K; row (k,t), column j = ∂f_k/∂x_j at t |
| `dg` | K×P×Tg×K; entry (k,p,t,l) = ∂g_kp/∂x_l at t |
| `dh` | (K·Tg)×K; row (k,t), column l = ∂h_k/∂x_l at t |
| `traj_default` | T×K model integration at `k0`, `x0` with reltol 1e-6 |
| `traj_tight` | Same, with reltol 1e-10 |
| `aux_tight` | T×K(K+1) auxiliary integration from t₀ with reltol 1e-10: states first, then Φ in column-major order (Ph11, Ph21, …) |
| `aux_initial_Phi` | K×K Φ(t₀) actually used |

## `spline` (Phase 2)
| Field | Contents |
|---|---|
| `order` | Spline order (4) |
| `autoknots` | Whether automatic knot placement was used |
| `knots_input` | Knots before automatic placement, normalized to [0,1] |
| `knots` | Knots as used, normalized to [0,1] |
| `card` | 1×L basis sizes |
| `scaled`, `scaled_gm`, `scaled_fine` | Time grids mapped to [0,1] |
| `B{k}`, `dB{k}` | T×card_k basis and d/dt on the data grid (derivative already divided by range(t)) |
| `basis_gm`, `dbasis_gm` | Same on the Tg grid |
| `B_fine`, `dB_fine` | Same on the fine grid |
| `grid`, `grid_basis{k}`, `grid_dbasis{k}` | Direct `BSpline` evaluation on `linspace(0,1,101)` (in scaled time, so the derivative is not divided by range(t)) |

## `smoother` (Phase 3)
Single FWLS step, starting from the initial variances:

| Field | Contents |
|---|---|
| `variances_init` | T×L starting variances |
| `delta_step1{k}` | Spline coefficients after one weighted least-squares step |
| `noise_start_step1` | L×2 `lsqnonneg` start (σ², τ²) for the noise MLE |
| `sigma2_step1`, `tau2_step1`, `variances_sm_step1` | Results after one variance update |

Converged smoother:

| Field | Contents |
|---|---|
| `delta{k}` | Final spline coefficients |
| `sigma2`, `tau2` | Noise parameters |
| `variances_sm` | T×L variances on the data grid |
| `variances_gm` | Tg×L variances on the inference grid |
| `smoothed`, `dsmoothed` | Tg×L smoothed values and derivatives |
| `smoothed_fine`, `dsmoothed_fine` | Tf×L |
| `lincomb_data{k}` | card_k×T linear map from data to coefficients |
| `var_delta{k}` | card_k×card_k coefficient covariance |

| Field | Contents |
|---|---|

| `betas` | ncand×P one-step GM estimates |
| `errors` | 1×ncand generalized sums of squares |

## `steps` (Phase 4a, first-iteration β)
One EKF prediction per interval, starting from `x0(:, n)` over `tspan(:, n)`:

| Field | Contents |
|---|---|
| `beta` | β used for all steps |
| `x0` | K×(Tg−1) starting states |
| `tspan` | 2×(Tg−1) interval endpoints |
| `tout` | 21×(Tg−1) integration output times |
| `out` | 21×K(K+1)×(Tg−1) raw auxiliary output |
| `Q`, `Phi` | K×K×(Tg−1) process noise and propagator returned by `cumulative_noise` (after the `FilterPatched` correction when patched) |

## `iterations` (Phases 4–6)
All arrays are stacked over iterations along the last dimension. Iteration i uses β = `beta(i,:)` and produces `beta(i+1,:)`.

| Field | Contents |
|---|---|
| `n` | Number of iterations |
| `beta` | (n+1)×P; row 1 is the estimate after IC selection |
| `SS` | 1×n generalized sums of squares |
| `qp_relerr` | 1×n: independent QP re-solve vs. `gm.estimate` |
| `xbar` | K×Tg×n smoothed means |
| `P`, `sd` | Smoothed covariances (K×K×Tg×n) and standard deviations |
| `covar_raw` | Joint covariance as returned by `Filter.EKS`: smoothed states (K·Tg, state-major), then measurement errors (L·Tg, state-major) |
| `covar_aug` | (K·Tg + L·T)² after `augment_covariances`; the measurement block is on the full data grid |
| `V` | (K(Tg−2))² residual covariance at interior time points |
| `variances_XdX` | (2K·Tg)² covariance of [X; dX] |
| `smoothed_filtered`, `dsmoothed_dfiltered` | Tg×K state and derivative estimates used by GM |
| `design`, `response` | (K(Tg−2))×P and (Tg−2)×K GLS inputs |

## `final`

| `fitted_fine`, `dfitted_fine` | Tf×K |

## `selfcheck`
| Field | Contents |
|---|---|
| `performed` | Whether the comparison with `EGM.estimate` was run (false for `STAT5_patched`) |
| `beta_relerr` | Final β of the replay vs. `EGM.estimate` |
| `history_relerr` | Full β history vs. `EGM.estimate` (NaN if the lengths differ) |
| `icmean_relerr` | Selected initial-condition mean vs. `EGM.estimate` |
| `qp_max_relerr` | Largest `qp_relerr` over the iterations |
